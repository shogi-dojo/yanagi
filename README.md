# Yanagi (柳)

Deterministic Japanese → Ukrainian transliteration and policy enforcement gem.

柳 (*yanagi* = willow / верба) — a symbol of Ukraine and a tree equally at home in Japanese poetry.

## Features
- Zero runtime dependencies — stdlib only (`yaml`, `json`, `set`, `unicode_normalize`)
- Mode A: Deterministic kana/romaji to Ukrainian Cyrillic rendering
- Mode B: Lexicon-anchored prose audit and policy violation detector
- Synchronisation & validation against project transliteration policies

## Installation

Add this line to your application's Gemfile:

```ruby
gem 'yanagi'
```
